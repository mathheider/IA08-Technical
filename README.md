# IA08-Technical

This project is a simple drawing application for Android, built with Jetpack Compose.

## Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone https://github.com/mathheider/IA08-Technical.git
   ```
2. **Open in Android Studio:**
   - Launch Android Studio.
   - Select "Open an Existing Project".
   - Navigate to the cloned repository and open it.

3. **Build the project:**
   - Wait for Android Studio to sync the Gradle files.
   - Click on "Build" > "Make Project" from the top menu.

4. **Run the app:**
   - Select an emulator or connect a physical device.
   - Click the "Run" button (the green play icon) in the toolbar.

## How to Use the App

- **Change Brush Color:** Tap on the "Black", "Red", or "Blue" buttons to select a color for your brush.
- **Adjust Brush Size:** Use the slider to increase or decrease the thickness of the brush strokes.
- **Draw:** Press and drag your finger across the screen to draw on the canvas.
- **Undo:** Made a mistake? Tap the "Undo" button to remove the last stroke you drew.
- **Clear Canvas:** To start over, tap the "Clear" button to erase everything on the canvas.
